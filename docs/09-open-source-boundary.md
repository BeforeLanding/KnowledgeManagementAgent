# Open-source boundary

The public repository may contain generic code, company-neutral schemas, synthetic journals/emails, Mock Providers and aggregate benchmark methodology.

It must not contain employer documents, real correspondence, names, addresses, shipment identifiers, internal endpoints, credentials, prompts derived from confidential policy, screenshots, raw traces, contract terms, private performance numbers or reconstructed Bad Cases that identify a source.

Real cases must be abstracted into synthetic patterns and reviewed under the employer's written data, IP and open-source rules. Private connectors implement the public Provider interfaces from a separate private repository. Access to data for work does not imply permission to train, evaluate externally, copy or publish it.

Apache-2.0 applies to this prototype. Company contributions or deployment-specific adapters require a fresh ownership and release review before distribution.
